1. Apa itu Algoritma?

Bayangkan kamu sedang membuat Mie Instan. Apakah kamu memasukkan bumbu dulu ke panci kosong, lalu merebus air, lalu menyalakan kompor? Tentu tidak, kan? Pasti mie-nya gagal total! 🍜

Algoritma adalah urutan langkah-langkah yang logis (masuk akal) dan runtut (berurutan) untuk menyelesaikan suatu masalah. Manusia pakai algoritma setiap hari tanpa sadar, dan komputer sangat membutuhkannya karena komputer tidak bisa berpikir sendiri!

2. Mengenal Pseudocode

Apa itu Pseudocode? 📝

Pseudo artinya "semu/palsu", dan Code artinya "kode". Jadi, Pseudocode adalah kode palsu yang mirip bahasa pemrograman, tapi menggunakan bahasa manusia (Inggris/Indonesia).

Tujuannya agar programmer bisa fokus menyusun "logika" program tanpa pusing memikirkan titik-koma (syntax) dari bahasa pemrograman asli.

Kata Kunci Umum

  • INPUT/READ : Membaca data
  • OUTPUT/PRINT : Menampilkan hasil
  • IF - THEN - ELSE : Percabangan (Kondisi)
  • FOR / WHILE : Perulangan

Contoh Kasus: Program Cek Kelulusan Siswa 🎓

Jika nilai lebih dari 75 maka "Lulus", selain itu "Remedial".

1 Algoritma (Bahasa Sehari-hari)

  1. Minta pengguna memasukkan nilai siswa.
  2. Cek apakah nilai tersebut lebih besar dari 75.
  3. Jika iya, tampilkan pesan "Lulus".
  4. Jika tidak, tampilkan pesan "Remedial".
  5. Selesai.

2 Pseudocode

INPUT nilai
IF nilai > 75 THEN
    PRINT "Lulus"
ELSE
    PRINT "Remedial"
ENDIF

3. Dari Pseudocode ke Bahasa Nyata

Nah, mengapa kita belajar Pseudocode? Karena strukturnya sangat mirip dengan bahasa pemrograman asli (nyata). Mari kita hubungkan pseudocode cek kelulusan di atas ke dalam dua bahasa pemrograman populer: Python dan C++. 

// Ini adalah rancangan sebelum diubah jadi kode asli
INPUT nilai
IF nilai > 75 THEN
    PRINT "Lulus"
ELSE
    PRINT "Remedial"
ENDIF

# Di Python, indentasi (spasi) sangat penting menggantikan ENDIF
nilai = int(input("Masukkan nilai: "))

if nilai > 75:
    print("Lulus")
else:
    print("Remedial")

// Di C++, menggunakan kurung kurawal {} dan titik koma ;
#include <iostream>
using namespace std;

int main() {
    int nilai;
    cin >> nilai; // INPUT
    
    if (nilai > 75) {
        cout << "Lulus"; // PRINT
    } else {
        cout << "Remedial";
    }
    
    return 0;
}
💡

Perhatikan! Meskipun bahasa pemrogramannya berbeda-beda (Python vs C++), logika berpikirnya (Pseudocode) tetap SAMA. Itulah pentingnya belajar logika dan pseudocode sebelum ngoding!
